TRAVORA Travel Platform

Launch TRAVORA Web Application

TRAVORA runs with an integrated FastAPI backend, dynamic trip routing, real-time sensing, and 802 Indian districts.

1
Double-click start_server.bat (Desktop) or start_mobile_server.bat (9:16 Mobile View).
2
Your default web browser will open to http://localhost:8000 or http://localhost:8001.
3
Experience TRAVORA on desktop or inside the 9:16 smartphone simulator with live QR code for your actual phone!
Desktop Portal (http://localhost:8000) → 📱 Mobile 9:16 Studio (http://localhost:8001) → 📊 SQLite Database Studio
